[Zink](https://docs.mesa3d.org/drivers/zink.html) is an OpenGL implementation that translates the calls to Vulkan. This is useful specifically for Wine in [wow64 mode](https://gitlab.winehq.org/wine/wine/-/releases/wine-11.0#wow64), where it sometimes can't directly map graphics buffers, leading to a significant slowdown. This can be detected by looking for the log line `fixme:opengl:wow64_map_buffer Doing a copy of a mapped buffer (expect performance issues)`. The 32-bit Vulkan implementation doesn't have this problem, so translating the calls to Vulkan speeds the program back up to match the performance it would have had using the older win32 mode.
